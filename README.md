# 🌍 AI-Powered Smart Tourism Platform - Sri Lanka

An intelligent travel recommendation system that provides personalized destination suggestions and accommodation options in Sri Lanka based on user preferences, seasonal weather data, and machine learning.

## ✨ Features
- **Smart Recommendations:** Uses a Hybrid ML model to suggest the best places to visit.
- **Real-time Weather:** Integrates with Weather APIs to provide current conditions for destinations.
- **Accommodation Integration:** Provides top-rated hotel options with real-time pricing and booking links.
- **Interactive UI:** A modern, dark-themed cinematic interface built with React and Framer Motion.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Framer Motion
- **Backend:** Flask (Python)
- **AI/ML:** Scikit-learn (Hybrid Recommender System)
- **Database:** JSON-based location & seasonal data
